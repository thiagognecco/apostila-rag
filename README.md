## 🎯 Objetivo da Apostila

Criar guia completo e profundo sobre transição de **Retrieval-Augmented Generation (RAG) tradicional** para **Graph RAG**, cobrindo:

1. **Fundamentos**: O que é RAG, componentes, arquitetura
2. **Limitações**: Por que Naive RAG falha em produção
3. **Grafos**: Conceitos, triplas RDF, SPARQL
4. **Implementação**: Código Python pronto para usar
5. **Produção**: Governança, segurança, monitoramento, ROI
