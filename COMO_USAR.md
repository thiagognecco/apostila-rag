# 📚 APOSTILA RAG com Grafos - Como Usar

## 🚀 Abrir o Website

**Opção 1: MAIS FÁCIL (Recomendado)**
1. Abra a pasta onde você baixou os arquivos
2. **Clique 2 vezes** no arquivo `index.html`
3. Pronto! O website abre no navegador

**Opção 2: Se não funcionar**
1. Clique com botão direito em `index.html`
2. Selecione "Abrir com..." → Chrome/Firefox/Edge
3. Pronto!

---

## 📖 Como Navegar

### Menu Principal (Esquerda)
- 🏠 **Início** - Página inicial com resumo
- 📖 **Módulos** - Grade de 15 módulos (clique para ler)
- 🔗 **Grafo** - Visualização das relações entre módulos
- 📚 **Glossário** - 125+ termos técnicos explicados
- ⏱️ **Timeline** - Cronologia das 7 conversas
